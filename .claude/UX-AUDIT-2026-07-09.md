# UX Audit — Main Page (pre-interactions) — 2026-07-09

Five lenses (typography scale, spacing/rhythm, readability/scanning, mobile ergonomics, accessibility) run against the built page at 1728/1440/1024/390, cross-checked against the Figma export, then adversarially critiqued. Duplicates consolidated; killed findings dropped; modified recommendations applied. Locked elements (hero SVGs, tagline 36px, sub-line 24px, 200px case numerals, meta bar) untouched throughout.

## Verdict

The page is structurally excellent: the locked brutalist register renders faithfully at every width, spacing matches Figma within ~2px almost everywhere, aria-hidden discipline and contrast are near-exemplary, and heading hierarchy is clean. The real problems are concentrated in two places — secondary type runs one tier too large (resume role/date/body, status title), and a handful of responsive behaviors invert as the viewport narrows (11px terminal text at 1200px vs 16px at 390px, a 39px mobile CTA vs 44px desktop, 14px-tall tap targets under 40px arrow affordances). The single biggest win: replace the stepped terminal-band overrides with fluid clamps and widen the status cell — it fixes the worst legibility failure on the page, kills the non-monotonic scale, and unblocks the status-title fix in one pass.

## Notes for the interactions phase

- **Stretched links change the hover surface**: once `.link::after` covers cells 01–04, hover states should fire on the full cell (they will, via the anchor) and `:focus-visible` will trace the whole cell — design the hover/focus treatment at cell scale, on the drafting idiom. 05 ABOUT hovers on its padded label only.
- The `// INITIALIZING...` line becomes `aria-hidden` (item 5) — safe target for a typing/blink boot animation; keep the informative status rows static and announced. All animation must respect the existing `prefers-reduced-motion` kill-switch (`globals.css:186-194`).
- Moving `.vruleMid` to 32% below 1250 (item 1) shifts the interior-rule intersections — re-pin any crosshair/plus-mark animations anchored to those x-positions.
- Em-based `.desc`/`.title` max-widths (item 9) mean hover scale transforms will not reflow the measure.
- Arrow-out icons already visible at rest — keep it that way (no hover-only affordances).
- Disable the Next.js dev overlay when capturing animation QA screenshots; it contaminated the 390 captures.
